Owner, 2026-10-27, on APK-LEGAL.md starting its decisions at D1: "You mean D0? I think you missed the first one."
ferros counts from 0 everywhere: privilege levels count from 0 (KERNEL.md terms), dozenal versions start at Zil (0), and numbered IDs in docs (decisions D0…, open questions O0…, steps, phases) start at 0 too.

**Why:** consistency with the rest of the system; a list starting at 1 reads as having skipped the first entry.
**How to apply:** any new numbered scheme in code or docs starts at 0; if one started at 1 and nothing cites it yet, renumber it.
