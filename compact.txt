2. Key Technical Concepts:
   - **spirix no_std 
chain**: `powi` on f32/f64 
is std-only (not in core); 
replaced with 
`f64::from_bits(((1023 + n)
 as u64) << 52)` bit 
manipulation (exact for 
powers of 2, no deps)
   - **IEEE feature gate in
 spirix**: `ieee = 
["dep:num-complex"]` 
feature gates circle_rust, 
rust_circle, scalar_rust 
f-impls, rust_scalar 
f-impls, operator f-impls. 
`num-complex` made 
optional. Integer 
conversions always 
available.
   - **ihi 0.0.3**: `spirix
 = { version = "0.0.11", 
default-features = false }`
 — no_std, no getrandom, no
 std
   - **M1 boot chain**: 
SecureROM (EL3, silicon) → 
iBoot (EL3→EL2, reads 
LocalPolicy from SEP) → 
m1n1 (EL2, Asahi's 
bootloader) → ferros 
payload
   - **LocalPolicy**: 
SEP-signed document 
controlling boot security. 
Owner-changeable via 
`bputil` in recoveryOS. 
Three levels: Full Security
 / Reduced Security / 
Permissive.
   - **EL2 on M1**: m1n1 
receives control at EL2. 
`fastboot oem pkvm disable`
 equivalent is built into 
m1n1. No QHEE equivalent. 
Full hardware access.
   - **m1n1 proxy**: Python
 REPL over USB-C for live 
hardware exploration — 
read/write physical memory,
 load payloads without 
reflashing. Built by Hector
 Martin (marcan), Asahi 
Linux project.
   - **Pixel 8 Tensor G3**:
 ARMv9, Cortex-X3+A715+A510
 (9 cores), Mali-G715 MP10,
 `fastboot oem pkvm 
disable` for EL2 ownership,
 LEVEL_3 Camera2
   - **Camera2 limitations 
vs direct hardware**: 16s 
max shutter, 12.5MP binned 
RAW, main sensor only for 
third-party — all HAL 
policy, not hardware. 
Direct CSI-2: 50MP true 
quad Bayer, unlimited 
exposure, all sensors, no 
ISP forced.
   - **Nanohub (Pixel 8)**:
 Cortex-M4 inside Tensor G3
 owns all IMU/baro/ALS 
sensors via mailbox. Goodix
 fingerprint → Titan M2 
(not AP-accessible).
   - **SEP (M1)**: Touch ID
 → SEP directly, never 
accessible to AP at any 
privilege level. FaceTime 
camera is USB internally.
   - **HAL trait split**: 
`ferros_hal` → trait 
definitions; 
`ferros_hal_qcm6490`, 
`ferros_hal_pixel8`, 
`ferros_hal_m1` as 
implementations. Start with
 `UsbBulk` trait for 
PT/bridge.
   - **Strip photography**:
 MIPI CSI-2 row readout at 
pixel clock speed = tens of
 thousands of 
strips/second. Camera2 API 
rate limits don't apply at 
hardware level.
